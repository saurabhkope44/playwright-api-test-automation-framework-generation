Authentication

Credentials live in the AuthCredentials sheet, separate from the API test cases. Test cases only reference an AuthRef.
⚠︎
Local demo storage. Credentials entered here are kept in this browser's localStorage, which is not secure storage. Use placeholder values such as ${API_KEY} for anything real and inject secrets from your CI vault at run time.

OAuth2 configuration

One row per flow in the OAuth2Config sheet. Use the helpers to build authorization URLs and token requests for your framework.

Environments

Environments are a convenience layer. A test case keeps its own BaseURL unless you explicitly apply an environment to it.

TestConfig sheet

Chains

Ordered request sequences such as create → read → update → delete. Steps with a missing or out-of-order dependency are flagged.

Project data

Everything is kept in localStorage under the keys apiTestCases, authCredentials, testConfig, chains, oauth2Config, environments and appSettings.

Using the export in Playwright

This studio manages and exports data only; it never calls your APIs. The runner below reads the exported workbook and drives the requests.

Serialization formats

Headers
Content-Type:application/json;Accept:application/json
Cookies
sessionId=test-session-123;userId=1001
Path params
userId=1 for endpoint /users/{userId}
Query params
limit=10&skip=0
Extract variables
$.id->POST_ID;$.token->AUTH_TOKEN
Assertions
$.id=equals:1;$.name=exists;Header:Content-Type=contains:json
Response time
ResponseTime=lessThan:5000 stored as an assertion
